Problème

Proposer un site pour découvrir des randonnées, gérer des parcours et afficher une carte, tout en apprenant les bases du développement web.

Solution

Un site full stack en PHP avec comptes utilisateurs, une page de gestion (CRUD) des randonnées, une carte en SVG et une base de données MySQL.

Impact

Un premier projet web mené de bout en bout : front, back et base de données.

À propos du projet

Premier projet web réalisé en formation (BUT) : un site pour découvrir et gérer des randonnées. Il réunit les pages du site, des comptes utilisateurs et une page de gestion des parcours reliée à une base de données, avec une carte des parcours en SVG. Un projet qui m'a permis de construire une application full stack de bout en bout : front, back et base de données.

Données

Les randonnées (nom, distance, difficulté, description) et les comptes utilisateurs sont enregistrés dans une base de données MySQL, interrogée en PHP via PDO.

MySQLComptes utilisateursRandonnées (CRUD)

Démarche technique

Un back-end PHP (PDO) dialogue avec une base MySQL. Les pages sont intégrées en HTML / CSS. La page de randonnée s'organise autour d'une carte en SVG, avec un panneau de filtres et un panneau d'informations.

Réalisations

  • Pages du site : accueil, randonnées, paramétrage, connexion et inscription.
  • Comptes utilisateurs : formulaires d'inscription et de connexion reliés à une base MySQL (PDO).
  • Page de gestion (CRUD) des randonnées : nom, distance, difficulté, description.
  • Maquette puis intégration HTML / CSS.
  • Page de randonnée : carte en SVG avec panneau de filtres et d'informations.
